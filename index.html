Pivov YouTube Watch

Pivov YouTube Watch jest prywatnym modułem systemu Pivov Watch służącym do monitorowania subskrybowanych kanałów YouTube, wykrywania nowych materiałów oraz wysyłania powiadomień e-mail.

Jak działa

Aplikacja korzysta z Google OAuth 2.0 i żąda wyłącznie minimalnych uprawnień potrzebnych do działania.

  • youtube.readonly — odczyt subskrypcji i metadanych YouTube potrzebnych do wykrywania nowych materiałów.
  • gmail.send — wysyłanie powiadomień e-mail.

Aplikacja nie odczytuje skrzynki Gmail, nie usuwa ani nie modyfikuje wiadomości oraz nie publikuje ani nie modyfikuje treści na YouTube.

Przetwarzanie danych

Konfiguracja i dane operacyjne Pivov YouTube Watch są przetwarzane i przechowywane lokalnie na urządzeniu właściciela Pivov Watch, z wyjątkiem komunikacji niezbędnej do korzystania z Google API.

Pivov YouTube Watch

Pivov YouTube Watch is a private module of the Pivov Watch system used to monitor subscribed YouTube channels, detect new content, and send email notifications.

How it works

The application uses Google OAuth 2.0 and requests only the minimum permissions required for its functionality.

  • youtube.readonly — read YouTube subscriptions and metadata required to detect new content.
  • gmail.send — send email notifications.

The application does not read the Gmail inbox, delete or modify email messages, or publish or modify YouTube content.

Data processing

Pivov YouTube Watch configuration and operational data are processed and stored locally on the Pivov Watch owner's device, except for communication required to use Google API services.
